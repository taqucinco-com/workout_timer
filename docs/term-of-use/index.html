Workout Timer 利用規約

第1条（適用）

本規約は、Workout Timer（以下「本アプリ」）の利用に関する条件を定めるものです。利用者は、本規約に同意した上で本アプリを利用するものとします。

第2条（サービス内容）

本アプリは、インターバルトレーニング向けのタイマー機能を提供します。時間設定には音声入力を利用できます。

第3条（音声認識）

音声入力機能は、端末のマイクおよびAppleが提供する音声認識機能（Speech framework等）を利用します。利用には端末上での許可が必要です。許可しない場合でも、音声入力以外の機能は利用できます。

  1. 音声入力の際、録音された音声データは文字へ変換するためにAppleの音声認識機能に渡され、端末の設定や言語等によってはAppleのサーバーに送信されて処理されることがあります。
  2. 前項の音声データおよびその認識結果は、Appleの利用規約およびプライバシーポリシーに従って取り扱われます。運営者は、Appleによる当該データの保存、利用、第三者への提供その他の取り扱いについて関与できず、これらに起因して利用者に生じた損害について、運営者は責任を負いません。
  3. 運営者は、音声データをAppleの音声認識機能への入力以外の目的で収集・保存しません。
  4. 音声データについて、Appleが音声認識機能の精度向上その他の目的で利用（機械学習への利用を含む）する場合があります。これは、運営者が決定または管理するものではなく、運営者は当該利用について責任を負いません。当該利用の可否は、利用者の端末設定およびAppleの定めに従います。
  5. 前各項は、利用者が音声データに関して法令上有する権利を制限するものではなく、また運営者に故意または重過失がある場合には適用しません。
  6. 他人の音声や、第三者の個人情報を含む音声を本アプリに入力する場合、利用者は、あらかじめ必要な同意を得るなど適法な方法で行うものとします。
